# Imam Nur Hidayat | Talent Acquisition Portfolio

A responsive personal website built with HTML, CSS, and vanilla JavaScript. The Indonesian option uses formal professional Indonesian.

## Files

Keep every file together in one directory. No nested asset folders are needed.

- `index.html`: Main portfolio website
- `style.css`: Responsive layouts and styles for desktop and mobile
- `script.js`: Language selector, mobile navigation, reveal effects, and horizontal carousels
The Download CV button downloads Imam-Nur-Hidayat-CV.pdf directly.
- `Imam-Nur-Hidayat-CV.pdf`: CV document
- `imam-profile-pastel.png`: Profile photo on a pastel blue background
- `speciality-*.webp`: Six individual recruitment illustrations
- `bnsp-hr-supervisor.webp`, `myskill-talent-acquisition.webp`, `bnsp-competency-units.webp`: Certificate images

## Run locally

Open `index.html` in a browser. Keep all files in the same directory so the images load correctly and the CV downloads directly. The website starts in English by default; use the language control to switch to formal Indonesian.

## Publish with GitHub Pages

Upload all files directly to the repository root and enable GitHub Pages in repository settings.
